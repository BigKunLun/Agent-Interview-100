工具不是答案，
场景才是。

LLM/Agent 评估工具分两类：评估框架负责定义指标和跑评估，比如 Ragas、DeepEval；评估平台负责评估、监控和协作，比如 LangSmith、Braintrust、Langfuse。两者互补，不是二选一。

Ragas

RAG 的四个专用指标，
每个怎么算。

Ragas 的重点不是通用评分，而是 RAG 链路的两端：检索上下文够不够、回答有没有基于上下文。

Ragas 的四个 RAG 专用指标
指标含义计算范围
Faithfulness回答是否基于检索到的上下文，非幻觉提取回答中的声明，检查每个声明是否被上下文支持0–1，越高越好
Answer Relevancy回答与问题的相关程度从回答反向生成问题，比较生成问题与原问题的相似度0–1
Context Precision检索到的上下文中有多少是相关的检索结果中，相关段落排名越高分越高0–1
Context Recall相关信息是否都被检索到了参考答案中的信息是否都能在检索上下文中找到0–1

三个平台

全栈、专业评估、
开源观测。

LangSmith 强在 LangChain 集成；Braintrust 强在专业评估和 A/B；Langfuse 强在开源、自部署和 OTel。

LangSmithLangChain 全栈平台。核心能力：Tracing 自动追踪 LangChain / LangGraph；Datasets；内置与自定义 Evaluators；Playground；生产监控；人工标注。
Braintrust专业评估和迭代。核心能力：声明式 Eval Framework；Online Evals；Prompt Playground；内置 A/B Testing；自动记录所有 LLM 调用。
Langfuse开源可观测性，原文称它是最流行的开源替代方案。核心能力：完全开源可自部署；OTel 兼容；框架无关；Trace / Span；在线和离线评估；成本追踪；Prompt 版本管理。
DeepEval / Promptfoo / Giskard原文列出的其他评估框架：DeepEval 通用开源评估；Promptfoo 做 Prompt 对比测试；Giskard 做安全和偏差测试。

常见误区 / 面试追问

两个误区，
两个追问。

工具不是二选一；商业也不一定比开源好。数据隐私和从零搭建是常见追问。

误区 01

“选一个工具就够了”

评估框架（Ragas）和评估平台（LangSmith / Langfuse）是互补的。Ragas 定义 RAG 评估的指标，平台提供运行评估和追踪的基础设施。生产系统通常需要两者结合。

误区 02

“商业平台一定比开源好”

Langfuse 作为开源方案在很多场景下已足够好，且可以自部署保证数据安全。商业平台的优势在企业级支持、更丰富的 UI 和更好的协作功能。

追问 03

这些工具如何处理数据隐私？

评估工具会记录 LLM 的输入输出，可能包含敏感数据。三条措施：自部署 Langfuse，保证数据不出组织；配置 PII 脱敏规则；只在开发环境记录完整数据，生产环境只记录指标。

追问 04

如何从零开始搭建评估体系？

三步走：先用 Langfuse / LangSmith 加 Tracing，了解 Agent 的行为；构建 Golden Dataset，用 DeepEval / Ragas 定义指标；集成到 CI/CD，实现自动化回归测试。
